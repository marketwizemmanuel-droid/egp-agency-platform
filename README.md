## ✦ Core Features

- **Editorial Portfolio & Case Studies**: Asymmetric high-impact showcase across 6 disciplines (`Branding`, `Graphic Design`, `Digital Marketing`, `Web Design & Development`, `Video Production`, `Motion Graphics`) with dedicated case study drawers and confidential client support.
- **Results / Impact Matrix**: Monolithic typographic philosophy (`STRATEGY. CREATIVE. IMPACT.`), qualitative brand pillars, and verified delivery benchmarks.
- **Interactive Project Intake (Start a Project)**: Conversion pipeline with 8-field project brief, spam protection, and direct transmission to `egpagency001@gmail.com`.
- **EGP Assistant (Server-Side AI)**: Custom-branded floating AI assistant powered server-side by Gemini 3.8 Flash (`@google/genai`) for instant agency Q&A and 7-step guided project intake.
- **Client Roster & Authentic Testimonials**: Subtle editorial partner grid with NDA-protected stealth mandates and verified client reviews.
- **International Creative Direction**: Apple × Nike aesthetic discipline, Stark Black (`#08080A`), Pure White (`#FFFFFF`), and strategic EGP Purple (`#7928CA`) accents.
- **Enterprise SEO & Meta**: Open Graph social cards, Twitter summary cards, SVG monogram favicon, Schema.org JSON-LD, `sitemap.xml`, and `robots.txt`.

## ✦ Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/egp-agency.git
cd egp-agency

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env
```

### Running Locally

```bash
# Start development server (Express backend + Vite middleware)
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build

```bash
npm run build
npm start
```
